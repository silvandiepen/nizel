# Realistic benchmark fixtures

Frozen copies, so results stay comparable as the repository changes:

- `readmes.md`: every package README and the root README, concatenated.
- `documentation.md`: every page of `documentation/` and `docs/` (100 KB+).
- `tables.md`: `documentation/guides/benchmarks.md`, a table-heavy page.
- `nested-lists.md`: a release plan with three to four levels of mixed
  ordered, bullet and task lists, links and continuation paragraphs.
